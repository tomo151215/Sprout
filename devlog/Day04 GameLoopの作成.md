# GameLoopを作る

## GameLoopとは
ゲームはパラパラ漫画のように画面を切り替え続けることで動かしていきます。その時の「切り替え続ける仕組み」がGameLoopです。

### GameLoopの基本
GameLoopとは、ゲームが起動している間ずっと回り続ける処理です。以下の形が基本です。
```java
while (running) {
    update();
    render();
}
```
update()はゲームの状態を更新する処理で、オブジェクトの座標更新や当たり判定、アニメーションの進行などを行います。一方、render()はupdate()によって更新された内容を画面に描画します。ゲームは基本的に、この「更新 → 描画」のサイクルを繰り返すことで成り立っています。
しかし、単純にこれを繰り返すだけでは、マシンの性能によって1秒間のループ回数（フレームレート）が変動し、PCの性能ごとにゲーム内の時間の進み方が変わってしまいます。
これを防ぐため、「描画（render）の回数はPCの性能に委ねるが、状態の更新（update）は現実の一定時間に対して必ず一定の回数（頻度）で行う」という制約を設けます。これにより、どんな性能のPCであっても、ゲーム内の時間を現実と同じスピードで一律に進行させることができます。

### GameLoopはスレッドで動かす
JavaのSwingでは画面描画をEDTというスレッドで行います。そこで仮にゲームループを実行してしまうと、`update`、`render`以外の操作（例えば入力、サウンド、ネットワークなど）を行えなくなり、ゲームになりません。ゆえにGameLoopは別スレッドで動かし、ほかの操作に影響を与えないようにします。
