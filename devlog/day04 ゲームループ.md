# GameLoopを作る

## GameLoopとは
ゲームはパラパラ漫画のように画面を切り替え続けることで動かしていきます。その時の「切り替え続ける仕組み」がGameLoopです。

### GameLoopの基本
GameLoopとは、ゲームが起動している間ずっと回り続ける処理です。以下の形が基本です。
```java
while (running) {
    update();
    render();
}
```
`update()`はゲームの状態更新です。オブジェクトの座標更新や当たり判定、アニメーション更新などを行います。`render()`は`update()`で更新された内容を実際に描画します。つまりゲームは更新→描画→更新→描画→を繰り返して成り立っているということです。しかし、これだけだと、高性能なPCと低性能なPCで１秒当たりのループ回数が変化してしまい、PCによってゲーム内の時の進みが変化してしまいます。
